개인정보처리방침

gws-app은 Google Workspace CLI 학습을 위한 개인용 앱입니다.

접근 범위와 이용 목적

이 앱은 사용자가 Google OAuth 동의 화면에서 명시적으로 승인한 권한 범위 내에서만 Google Workspace 데이터에 접근합니다. 데이터는 사용자가 요청한 기능 실행과 개인 학습 목적으로만 이용합니다.

데이터 저장

이 앱이 저장하는 Google 사용자 데이터와 인증 정보는 사용자의 컴퓨터에만 저장합니다. 별도의 운영 서버나 이 GitHub Pages 웹사이트에는 저장하지 않습니다.

제3자 제공

Google 사용자 데이터를 제3자에게 제공하거나 판매하지 않습니다. 광고 목적으로 이용하지 않습니다.

Google API 정책 준수

gws-app의 Google API에서 받은 정보의 이용은 제한적 사용(Limited Use) 요구사항을 포함한 Google API 서비스 사용자 데이터 정책을 준수합니다.

접근 권한 철회 및 데이터 삭제

사용자는 Google 계정의 연결 관리에서 언제든 앱의 접근 권한을 철회할 수 있습니다. 컴퓨터에 저장된 데이터와 인증 정보는 사용자가 직접 삭제할 수 있습니다.
